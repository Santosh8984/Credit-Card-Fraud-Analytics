# Credit Card Fraud Analytics

## Project Overview

This Power BI project analyzes credit card transactions to identify
fraud patterns, transaction-value risk, and financial exposure.

## Business Objective

The objective is to understand:

- Overall fraud exposure
- When fraud risk appears
- Which transaction values are riskier
- Where financial exposure is concentrated
- What management should investigate

## Key KPIs

- Total Transactions: 285K
- Fraud Transactions: 492
- Fraud Rate: 0.17%
- Total Transaction Amount: $25.16M
- Fraudulent Amount: $60.13K

## Key Findings

- Overall fraud rate is 0.17%.
- Higher-value transactions show higher observed fraud rates.
- The $500+ transaction segment has the highest observed fraud rate at 0.37%.
- The $500+ segment accounts for approximately $31.19K in fraudulent transaction value.
- Further investigation should focus on higher-value transaction risk.

## Tools Used
